# 멍멍 카페 MVP 명세

커피 라인 하나로 "수학 문제 풀기 → 에너지 → 머지로 음료 만들기 → 서빙 → 레벨업"이 끝까지 돌아가는 첫 버전이다.

**이 게임은 학습용이다. 에너지는 수학 문제를 맞혀야만 얻는다(시간이 지나도 차오르지 않는다).** 모든 진행의 출발점이 문제 풀기다. dog_village에서 간식을 수학으로만 얻던 구조와 같다.

## 1. 범위

**만든다**
- 커피·과일음료·쿠키·케이크 4라인 8단계 머지, 라인별 생성기(design-guide.md 해금표: Lv1 커피, Lv3 과일, Lv5 쿠키, Lv8 케이크)
- 손님 3종, 동시에 최대 3명, 주문 1~3개(레벨에 따라 해금된 라인에서 섞여 나옴)
- 수학 문제 창: 학년 선택(1~6학년), 난이도 자동 조절, 힌트, 정답 보상 에너지
- 코인, 경험치(별), 카페 레벨 1~9, 에너지
- 오늘의 학습 기록(푼 문제 수, 오늘 목표 10문제)
- 바리스타 3동작 연출
- localStorage 자동 저장

**만들지 않는다(다음 버전)**
- 생성기 업그레이드, 인테리어 상점
- VIP·단체 손님(Lv10+), 거스름돈 계산 문제(카페 상황 문제는 다음 버전)
- 효과음·배경음

## 2. 화면 배치

`docs/layout-mockup.png`는 아래 좌표로 그림을 실제로 합성해 본 화면이다(절반 크기). 구현 결과가 이 그림과 비슷하게 보여야 한다.

무대는 1080×1920 고정 좌표다. 아래 숫자는 모두 무대 좌표(px)이며, 화면에 맞춰 통째로 축소한다. 남는 여백은 `#F6E7D8`로 채운다.

| 영역 | y 범위 | 내용 |
| --- | --- | --- |
| HUD | 0–140 | 코인, 레벨·경험치 바, 에너지 + 문제 풀기 버튼 |
| 카페 장면 | 0–880 | 배경, 손님, 바리스타, 말풍선 (HUD가 위에 겹침) |
| 머지 보드 | 880–1900 | 7×7 칸 |

> 기획서에는 보드가 7×9로 적혀 있지만, 장면 공간을 확보하려고 MVP는 **7×7**로 한다.

### 배경 (`assets/bg/bg_cafe_lv1.png`, 원본 768×1376)
- 가로를 1080에 맞춰 1.40625배 확대한다(1080×1935).
- `top: -526px`에 놓는다. 그러면 카운터 앞판 아래 끝이 y≈880(보드 위)에, 카운터 윗면이 y≈557에 온다. 천장과 조명은 위로 잘린다.
- 오른쪽 아래의 작은 반짝이 표시는 보드에 가려지므로 처리하지 않는다.

### 카운터 덮개 (손님이 카운터 뒤에 서 보이게)
- 같은 배경 이미지를 같은 위치에 한 번 더 놓는다. `clip-path`로 **y 575 아래만** 보이게 잘라서 손님 위 레이어에 둔다.
- 레이어 순서(아래→위): 배경 → 손님 → 카운터 덮개 → 바리스타 → 말풍선 → HUD → 보드 → 드래그 중인 아이템 → 토스트

### 손님 자리
- 3자리, 가로 중심 x = 400, 640, 880
- 손님 그림(384×384)을 260×260으로 표시한다. 그림 안에서 몸 아래 끝이 캔버스 바닥에서 20px 위에 있다.
- 요소의 top = 351 (몸 아래 끝이 y≈597, 카운터 덮개에 약 22px 가려짐)
- 들어올 때 오른쪽에서 미끄러져 들어오고(0.4초), 나갈 때 오른쪽으로 나간다.

### 바리스타
- 그림(768×768)을 340×340으로 표시. 가로 중심 x = 140, 그림 바닥이 y = 885
- 기본 `barista_idle`. 손님 입장·레벨업 때 `barista_greet` 1.5초, 서빙 때 `barista_serve` 1초 후 다시 idle.

### 주문 말풍선
- 손님 머리 위: 가로 중심은 손님과 같고, 아래 끝이 y≈440. 흰 바탕, 테두리 4px `#5B3A29`, 모서리 28px, 아래쪽 꼬리.
- 주문 아이템 아이콘 80×80을 가로로 나열. 전달된 아이템은 흐리게 + 초록 체크.
- 말풍선 아래 인내심 바(높이 10px): 60% 초과 `#8BD3A0`, 40–60% `#F6D365`, 40% 이하 `#F28B82`.

### HUD
- 반투명 흰색 알약 모양 3개(배경 `rgba(255,255,255,.85)`, 모서리 40px)
- 왼쪽: `ui_coin` 64px + 코인 수
- 가운데: `ui_star` 64px + "Lv.N" + 경험치 바(200px)
- 오른쪽: `ui_energy` 64px + "현재/최대" + 초록색 둥근 **＋ 버튼**(누르면 수학 문제 창). 에너지가 5 이하이면 ＋ 버튼이 살짝 통통 튄다.
- 오른쪽 위 구석(HUD 아래) 작은 알약: "오늘 N/10문제"

### 가로 화면(아이패드 landscape 10세대 기준)
주 사용 기기인 아이패드 10세대를 가로로 들면, 위 세로 배치 대신 **1440×1000** 무대를 쓴다(`js/config.js`의 `CONFIG.LAYOUTS.landscape`). 세로로 들면 지금까지 설명한 배치를 그대로 쓴다. 화면을 돌리면 즉시(새로고침 없이) 전환된다.

- 왼쪽 0–560px: 카페 장면(손님 3자리·바리스타). 카운터는 아직 전용 그림이 없어 임시 사각형(`#D9B99B`)으로 둔다 — 가로용 배경 그림이 생기면 `#landscapeCounter` 자리에 넣는다.
- 오른쪽 580–1420px: 7×7 머지 보드(칸 100px)
- HUD는 세로일 때와 같은 구성으로 위쪽에 가로로 걸친다.
- 손님 3자리는 왼쪽 패널 안에서 가로 중심 x = 95, 280, 465(그림 150×150)로 좁혀서 배치한다. 들어오고 나가는 연출은 세로와 같다.
- 보드 칸 수(7×7)·생성기 위치(행6·열3)·수치(에너지·보상·주문 규칙 등)는 세로·가로 공통이다. 화면 좌표만 다르다.

### 보드
- 판 배경 `#D9B99B`, 모서리 28px, x 30–1050, y 880–1900
- 칸 136×136, 간격 6px, 첫 칸 왼쪽 위 (46, 896)
- 칸 바탕 `#FFF6EA`, 테두리 3px `#E8D5C0`, 모서리 18px
- 아이템 표시 크기(칸 대비): 1–2단계 60%, 3–5단계 75%, 6–8단계 90%
- 8단계 아이템은 CSS 반짝임(은은한 금색 glow가 2초 주기로 깜빡임)

## 4. 규칙

### 생성기
- 라인마다 고정 칸(`js/config.js`의 `CONFIG.LINES[line].genRow/genCol`)에 하나씩. 끌어서 옮길 수 없다.
  - 커피: 행6·열3 (Lv1부터) · 과일: 행6·열1 (Lv3) · 쿠키: 행6·열5 (Lv5) · 케이크: 행0·열3 (Lv8)
  - 해금되지 않은 라인의 생성기는 보드에 아예 나타나지 않는다. 레벨업으로 해금되는 순간 그 자리에 생긴다.
- 탭하면 에너지 1을 쓰고, 그 생성기에서 가장 가까운 빈칸에 같은 라인 1단계 아이템이 튀어나온다(0.25초 포물선).
- 나오는 아이템: 1단계 85%, 2단계 15% (라인 공통)
- 빈칸이 없으면 토스트 "보드가 가득 찼어요" + 생성기 흔들림. 에너지는 쓰지 않는다.
- 에너지가 0이면 수학 문제 창이 바로 열린다(토스트 "문제를 풀면 에너지가 생겨요!").

### 드래그와 머지
- 아이템을 끌어서 놓는 곳에 따라:
  - 빈칸 → 이동
  - 같은 라인·같은 단계 아이템 → 머지: 놓은 칸에 다음 단계 생성, 원래 칸은 비움, 0.2초 커졌다 작아지는 연출 + 작은 반짝임
  - 다른 라인이거나 다른 단계, 또는 둘 다 8단계 → 자리 바꾸기
  - 생성기 → 원래 자리로 돌아감
  - 손님 → 아래 "서빙" 참고
  - 보드·손님 밖 → 원래 자리로 돌아감
- 드래그 중에는 아이템이 손가락 위에 1.1배로 떠 있고, 놓을 수 있는 칸에 테두리 강조.

### 손님
- 게임 시작 2초 후 첫 손님. 빈자리가 생기면 3~6초 뒤 새 손님.
- 종류는 3종 중 무작위(같은 종이 동시에 둘 이상 와도 됨).
- 주문(카페 레벨별, `CONFIG.ORDER_RULES`): 그 레벨에 해금된 라인 중에서 아이템을 무작위로 섞어 뽑는다.
  - Lv1~2: 3~4단계, 1개
  - Lv3~4: 3~5단계, 1개(75%)·2개(25%) — 커피+과일 중에서
  - Lv5~7: 3~5단계, 1개(50%)·2개(50%) — 커피+과일+쿠키 중에서
  - Lv8~9: 3~6단계, 1~3개 — 커피+과일+쿠키+케이크 중에서
- 인내심: 75초 + 주문 1개 추가마다 15초
- 표정: 기본 `normal`, 인내심 40% 이하 `angry`, 서빙 완료 순간 `happy` 1.2초 후 퇴장
- 인내심이 다 떨어지면 `angry` 얼굴로 퇴장. 벌점은 없다.

### 서빙
- 주문에 들어 있는 아이템을 손님(말풍선 포함 영역)에 놓으면 그 아이템을 전달한다. 보드에서 사라지고 말풍선에 체크.
- 주문에 없는 아이템이면 원래 자리로 돌아가고 말풍선이 살짝 흔들린다.
- 주문을 모두 전달하면 보상을 받는다. 보상은 주문 아이템들의 가격·경험치 합.
- 팁: 완료 순간 인내심이 60% 넘게 남았으면 코인 +50% (말풍선 자리에 "팁!" 표시)

| 단계 | 3 | 4 | 5 | 6 | 7 | 8 |
| --- | --- | --- | --- | --- | --- | --- |
| 코인 | 10 | 18 | 30 | 50 | 80 | 130 |
| 경험치 | 3 | 5 | 8 | 12 | 18 | 30 |

### 레벨과 에너지
- 다음 레벨까지 경험치(`CONFIG.LEVEL_EXP_TO_NEXT`): Lv1→2 40, Lv2→3 120, Lv3→4 220, Lv4→5 380, Lv5→6 600, Lv6→7 850, Lv7→8 1150, Lv8→9 1500
- 레벨업 연출: 화면 가운데 "레벨 업!" 배너 1.5초 + 바리스타 greet
- 과일(Lv3)·쿠키(Lv5)·케이크(Lv8) 해금 순간 토스트로 알리고, 그 라인 생성기가 보드에 바로 나타난다.
- Lv9가 MVP 최고 레벨. 그 이상은 Lv8~9 주문 규칙으로 계속 플레이(VIP·단체 손님은 다음 버전).
- 에너지: 최대 60. **시간으로는 회복하지 않는다.** 수학 문제 정답으로만 얻는다(아래 5장).

### 시작 상태와 저장
- 처음 시작: 이름·학년 입력 화면(전작과 같은 흐름) → 코인 0, Lv1, 에너지 10, 보드에 생성기 + 커피콩 4개. 첫 손님 주문을 받는 순간 "문제를 풀어 에너지를 모아요" 안내 말풍선 1회.
- localStorage 키 `mungmungCafe.v1`에 보드, 코인, 레벨, 경험치, 에너지, 학년, 현재 난이도 단계, 오늘의 학습 기록(날짜·푼 수·맞힌 수)을 저장. 날짜가 바뀌면 오늘 기록을 0으로. 아이템 이동·머지·서빙·생성 때마다 저장.
- 손님은 저장하지 않는다(다시 열면 새 손님이 온다).
- 화면 구석 작은 버튼 "처음부터"(확인 창 후 저장 삭제). 브라우저 기본 `confirm()` 대신 게임 안 확인 창으로.

## 5. 수학 문제 (에너지 얻기)

전작 「멍멍 수학 마을」의 수학 기능을 **그대로 옮겨 온다**(`reference/dog_village_index.html`, 옮길 범위는 `CLAUDE.md` 참고). 같은 학생이 두 게임을 오가도 문제와 힌트가 같아야 한다. 아래는 이 게임에 맞게 정한 부분이다.

### 문제 창
- 화면 가운데 큰 카드(무대 기준 약 900×1100), 뒤는 반투명 어둡게. 게임 진행(손님 인내심)은 문제 창이 열린 동안 **멈춘다.**
- 위: "에너지 +6" 보상 표시, 학년·난이도 단계, 연속 정답 수
- 가운데: 문제(큰 글씨), 답 입력칸
- 아래: 숫자 키패드(0–9, 소수점, 지우기, 확인)를 CSS 버튼으로. 키보드 숫자·Enter·Backspace도 받는다.
- "닫기" 버튼으로 언제든 나갈 수 있다. "한 문제 더" 버튼으로 이어서 풀 수 있다.

### 채점
- 정답: 에너지 +6(최대치를 넘지 않음), 카드가 초록색으로 반짝, 에너지 아이콘이 HUD로 날아가는 연출, 오늘 푼 문제 +1
- 첫 번째 오답: 카드가 흔들리고 힌트 한 줄 표시(예: "10을 먼저 만들어 봐요"), 다시 입력
- 두 번째 오답: 정답과 짧은 풀이를 보여 주고 에너지 +2(포기하지 않게 작은 보상), 다음 문제로
- 에너지가 가득 차 있으면 문제는 풀 수 있지만 "에너지가 가득 찼어요" 표시(오늘 기록은 오름)

### 학년과 난이도
- 학년별 문제, 3단계 난이도, 단계 오르내리는 규칙, 3학년 단원별 문제는 전작 코드를 그대로 따른다.
- 전작 6학년 문제에는 소수 답이 있으므로 키패드에 소수점(.) 키를 둔다.
- 학년은 처음 시작할 때 이름과 함께 고르고, 설정에서 바꿀 수 있다.

### 밸런스 감각
- 생성기 1번 = 에너지 1. 4단계 음료 1잔은 커피콩 8개(약 7~8번 탭)가 필요하다.
- 그래서 **정답 1문제 ≈ 손님 1명 주문의 재료**가 되도록 정답 보상을 6으로 시작한다.

## 6. config.js에 둘 값
에너지(최대, 시작값, 정답 보상, 두 번째 오답 보상), 난이도 올림·내림 기준, 오늘 목표 문제 수, 생성 확률, 단계별 가격·경험치, 레벨별 필요 경험치, 레벨별 주문 규칙, 인내심 시간, 팁 기준·비율, 손님 등장 간격, 표정 바뀌는 기준. 숫자는 위 표의 값으로 시작한다.

## 7. 완료 기준
- [ ] `index.html`을 더블클릭해도, GitHub Pages에서도 동작한다
- [ ] 폰 세로 화면과 PC 브라우저 모두에서 무대 전체가 잘리지 않고 보인다
- [ ] 처음 열면 학년을 고르고 시작한다
- [ ] ＋ 버튼으로 문제 창이 열리고, 정답이면 에너지 +6, 오답 두 번이면 정답과 풀이가 나온다
- [ ] 3문제 연속 맞히면 난이도가 오르고, 문제 창이 열린 동안 손님 인내심이 멈춘다
- [ ] 에너지는 시간이 지나도 늘지 않는다. 0일 때 생성기를 누르면 문제 창이 열린다
- [ ] 생성기를 누르면 에너지가 줄고 커피콩이 나온다
- [ ] 같은 아이템 둘을 겹치면 다음 단계가 되고, 8단계는 더 합쳐지지 않는다
- [ ] 손님이 카운터 뒤에 서 있고(몸 아래가 카운터에 가려짐), 주문 말풍선과 인내심 바가 보인다
- [ ] 인내심이 줄면 표정이 바뀌고, 다 떨어지면 떠난다
- [ ] 맞는 음료를 손님에게 끌어다 놓으면 코인과 경험치가 오르고, 손님이 웃으며 떠난다
- [ ] 레벨 3·5·8에 도달하면 과일·쿠키·케이크 생성기가 차례로 보드에 나타나고, 손님 주문에도 섞여 나온다
- [ ] 다른 라인끼리는(단계가 같아도) 머지되지 않고 자리만 바뀐다
- [ ] 새로고침해도 보드, 코인, 레벨, 에너지, 학년, 오늘 푼 문제 수가 그대로다
- [ ] 바리스타가 손님 입장·서빙·레벨업 때 동작을 바꾼다
